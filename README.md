## Customer Sentiment Analysis

A customer analytics project developed during an internship to analyze large-scale Twitter/X customer feedback and uncover actionable insights related to customer experience, service quality, and brand perception.

## Business Objective

The goal of this project was to transform unstructured customer feedback into measurable business insights. By analyzing thousands of Twitter/X posts, the project aimed to:

* Identify recurring customer complaints and service issues
* Measure overall customer sentiment toward 
* Detect emerging trends in customer feedback
* Support data-driven decision making for customer service improvements

## Project Overview

The workflow combines automated social media data collection, text preprocessing, sentiment classification, and results analysis.

More than 5,000 customer feedback posts were processed and evaluated using multiple sentiment analysis approaches to improve robustness and compare model performance.

## Key Components

### Data Collection

* Twitter/X data extraction using Playwright
* Automated collection of customer feedback posts
* Structured export to CSV and Excel

### Data Processing

* Text cleaning and normalization
* Translation of multilingual content
* Preparation of datasets for analysis

### Sentiment Analysis

* VADER sentiment scoring
* DistilBERT sentiment classification
* Twitter RoBERTa sentiment classification

### Business Insights

* Customer complaint identification
* Service quality assessment
* Brand perception analysis
* Trend discovery across customer discussions

## Technologies Used

* Python
* Playwright
* Pandas
* Hugging Face Transformers
* VADER Sentiment Analysis
* DistilBERT
* Twitter RoBERTa

## Outcome

The analysis identified major customer concerns and sentiment patterns across thousands of customer interactions, helping translate social media feedback into actionable recommendations for business stakeholders.
